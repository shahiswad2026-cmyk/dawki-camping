# TN Dawki Night Camping Meghalaya

Static one-page website (HTML, CSS, JS). No build step, no backend.

- Open `index.html` to preview locally.
- Booking form opens WhatsApp (+91 9954943807) with the details pre-filled.

## Files
- `index.html`, `style.css`, `script.js`
- `images/hero-1..4.jpg`: hero slider (1600px wide)
- `images/gallery-1..8.jpg`: gallery (800px wide)

To replace a photo, overwrite the file in `images/` with the same name.

## Deploy (GitHub Pages)
Push to GitHub, then Settings > Pages > Deploy from branch > `main` / root.
